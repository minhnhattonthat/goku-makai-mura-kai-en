# Goku Makaimura Kai (PSP, ULJM-05265) English translation

Skill: translate-retro-game (Claude Code: plugin, enabled in .claude/settings.json; other agents: `<SKILL_DIR>/SKILL.md`). `python tools/skill.py` prints its folder (`$SKILL` below). Read it before ROM, text or QA work.

The disc holds a launcher plus **two games**: Goku Makaimura Kai (`USRDIR/REGOKUMAKAI`) and the original Goku Makaimura (`USRDIR/GOKUMAKAI`). Both are in scope (D9).

## Commands (run from repo root)
- Build:    `python -X utf8 tools/build.py` -> `build/goku_en.iso`, checks both dumps against `rom.sha1` first (`--identity`: must equal the dump)
- Marker:   `python -X utf8 tools/build.py --marker [ruler|torture] --out build/marker.iso` (ids / box rulers / every glyph; unpacked text in `work/marker/<re|go>/pkdata` = `BMS_DIR` for warp tours)
- Lint:     `python -X utf8 tools/lint.py -v` (width budgets per box `docs/re/boxes.md`, codes, glossary, untranslated; `script/keep_jp.txt` waives)
- Diff:     `python -X utf8 tools/diffcheck.py [ISO]` (build writes only text, font, PRX save strings + pointer table; the check runs it on a fresh build)
- Check:    `python -X utf8 tools/check.py` (tests + lint; the pre-commit hook runs this). Hook setup on a fresh clone: `git config core.hooksPath tools/hooks`
- Smoke:    `python -X utf8 "$(python tools/skill.py)/scripts/emu.py" "rom/Goku Makai-Mura Kai (Japan).iso" --out work/qa/smoke --route tools/routes/boot.txt --smoke` (the build: `build/goku_en.iso --out work/qa/smoke_en`)
- Warp:     `python -X utf8 tools/debug/warp.py re:stage_0201 --out work/qa/warp` (`--list`, `--all`; `re` Kai, `go` original; notes in `tools/debug/README.md`)
- Cover:    after a tour, `python -X utf8 tools/cover.py` then `textcover.py work/qa/cover work/qa/cover/strings.tsv --waive docs/text_unshown.tsv` (skill script)
- Release:  not written yet (phase 9): `python -X utf8 tools/release.py` (patch + verify; never publish without the user)
- Clean:    `python -X utf8 tools/clean.py` (published projects: lists rebuildable/downloadable files; `--yes` deletes)

## Recon commands
- Unpack ISO: `python -X utf8 tools/iso9660.py x "rom/Goku Makai-Mura Kai (Japan).iso" work/iso`
- Unpack archives: `python -X utf8 tools/kpd.py x work/iso/PSP_GAME/USRDIR/REGOKUMAKAI/datapack.kpd work/re` (`work/go`: GOKUMAKAI; `work/la`: LAUNCHER/LAUNCHER.KPD)
- Decode script: `python -X utf8 tools/bms.py FILE.bms`. Textures: `tools/ana.py x`, `tools/gimsheet.py`, `tools/sweep_gim.py`.

## Paths
- Original ROM: `rom/Goku Makai-Mura Kai (Japan).iso` (gitignored; SHA-1 in `rom.sha1`, checked by `tools/check_rom.py`).
- USA disc `rom/Ultimate Ghosts 'n Goblins (USA).iso` (D10): official English text, font and art for the original game, unpacked to `work/us`; see `docs/re/usa.md`.
- Emulator: PPSSPPHeadless QA fork qa-1 (`fetch_emu.py ppsspp-headless`, one machine-wide install in `%LOCALAPPDATA%\translate-retro-game\ppsspp-headless`); people and EBOOT dumps: PPSSPP v1.20.4 in `tools/ppsspp/` (gitignored). Savestates: `work/states/`.
- Text: `script/{re,go}/*.json` (`tools/script.py dump|check|stats`; format in `docs/re/text.md` §script/). Tables: `tbl/jp.tbl` (generated by `tools/mk_tbl.py`). Glossary: `glossary.md`. RE notes index: `docs/re/README.md`. Fonts and their licences: `docs/fonts.md`.

## Rulings
- Edit source files (.py .lua .asm .tbl .json) only with the file-edit tool; scripts here read and analyse, never `.replace()` and write back. The guard hook also blocks heredocs that write source.
- Subagents: dispatch the `.claude/agents/` types (translator, reviewer, visual-qa, playtester), never general-purpose. Exception: an Orca dispatched worker does the work itself, and does reviews itself in a fresh read-only pass.
- The user's decisions, with the options and reasons: `docs/decisions.md`. Read it before asking the user anything; add each new ruling there the same session.
- Player bug reports: GitHub issues (`gh issue list --label bug`). Copy the attached save into `work/states/`, reproduce in the emulator, fix, commit with `Fixes #N`, and update `docs/status.md`.
- OK is **circle**, cancel is cross. The launcher waits on the book screen: `start` then `circle` boots a game.
- `.bms` strings: slice by the offset table, never scan for NUL (`80 00` is a glyph).
- Two copies of everything: shared strings and textures must reach both games' archives, and a10 textures differ per game.
